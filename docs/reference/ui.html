UI reference

Screens, HUD parts and the styles they use.

#

Read-only client state for bindings.

  • .client() -> crate::ClientThe client's actions (menu_open, world_open, quit..), for a button's callback: a button may drive the client, a binding that only shows a value may not. source
  • .player() -> u64 source
  • .target() -> Option<abi::Target>The block or entity under the crosshair, as the client uses it for interactions. source
  • .attribute(a: &crate::Attribute) -> f64Own player's attribute, as the server says. Mods' attributes come too. Unlike World::attribute it takes no entity: the client only has its own player's. source
  • .effect_level(effect: &crate::EntityEffect) -> u32The level of effect on the local player, 0 without it (poisoned hearts). source
  • .swing_strength() -> f32How charged the next swing is, 0..1: for a bar of your own. source
  • .use_ticks_left() -> Option<f32>Ticks left of the item being used. source
  • .day_time() -> u64 source
  • .weather() -> u32The weather's id now (weathers::RAIN.id()), as the server says. source
  • .permission() -> u32The player's permission level (abi::permission). source
  • .component<T: Value>(c: &Component<T>) -> Option<T>Own player's synced component. Unlike World::component it takes no entity: another one's is component_of. source
  • .player_state() -> Option<abi::EntityState> source
  • .inventory_slot(slot: u32) -> ItemStackOwn inventory slot by index (the engine lays the inventory out from its groups; with the base game the hotbar comes first). source
  • .inventory_group(name: &str) -> Vec<ItemStack>The stacks of a group of the own inventory (hotbar, core:equipment...). source
  • .creative() -> boolThe local player is in creative mode. source
  • .outside_survival() -> boolThe local player's mode spares it damage and hunger: no bars to show. source
  • .game_mode() -> u32abi::game_mode. source
  • .component_of<T: Value>(entity: u64, c: &Component<T>) -> Option<T>Another entity's component the server shares with this client (SYNC_WATCHERS, or SYNC_MENU while its menu is open). source
  • .menu_owner() -> Option<u64>The entity the open menu is on (a block entity, a mob), if any. source
  • .menu_component<T: Value>(c: &Component<T>) -> Option<T>A component of what the open menu is on, synced with SYNC_MENU, for screens to bind to. source

#

A HUD element being registered (Registry::hud_element).

  • .rebuild_when(f: impl Fn(&crate::ClientView) -> u64 + Send + Sync + 'static)Rebuilds the layout when this revision changes. Keep changing text and numbers in bindings; use this for a different set of widgets, such as a new inspected block. source
  • .anchor(anchor: &str)Where it sits (hud_anchor::*). source
  • .order(order: i32)0 sits nearest the anchor's edge. source
  • .ui(f: impl Fn(&mut Ui) + Send + Sync + 'static)What it shows. source

#

A row of icons in the making (Ui::icons); it goes in as this goes.

  • .from_right()Filling from the right (hunger). source
  • .dir(dir: u32)Filling in direction dir (abi::ui_dir). source
  • .shaking()Jumping about at 4 or less (hearts near the end). source
  • .shaking_below(value: f32)Jumping about at value or less. source
  • .shaking_by(f: impl Fn(&ClientView) -> f32 + Send + Sync + 'static)Jumping about as much as f says (0 still, 1 a pixel, 2 two...): food with no saturation left, harder when nearly empty. source
  • .flash_on_gain(secs: f32)What it gains blinks for secs, and <class>_flash lights it where there is one (hearts healing). source
  • .flash_on_loss(secs: f32)What it loses blinks for secs (hearts hurt). source
  • .preview(secs: f32, f: impl Fn(&ClientView) -> f32 + Send + Sync + 'static)What the row would be at f's value, fading in and out every secs (what the held food would fill, as AppleSkin shows it). source
  • .overlay(f: impl Fn(&ClientView) -> f32 + Send + Sync + 'static)A second row at f's value in <class>_overlay icons over this one (saturation). source
  • .wave_while(pixels: f32, f: impl Fn(&ClientView) -> f32 + Send + Sync + 'static)While f is above 0 a wave runs along the row, pixels high (hearts regenerating). source
  • .max_by(f: impl Fn(&ClientView) -> f32 + Send + Sync + 'static)The halves the row holds, f's value (none: twice the count): past the count more rows go on above, closer the more there are (hearts past twenty health). source
  • .effect(kind: u32, amount: f32, f: Option<Box<dyn Fn(&ClientView) -> f32 + Send + Sync>>)Any abi::icon_effect by f's value (none: 1). source
  • .look_while(class: &'static str, f: impl Fn(&ClientView) -> f32 + Send + Sync + 'static)Drawn in class's icons instead while f is above 0 (food turned green by hunger). source

#

  • .world() -> World source
  • .taken_in(name: &str) -> Option<u32>In on_take, which slot of group name was taken from; None for another group's. source
  • .player() -> u64 source
  • .times() -> u32In on_take of a crafting grid's result (Slots::crafting), how many runs of its recipe that was (a shift-click crafts all that fit at once); 1 otherwise. source
  • .owner() -> Option<Holder>What the menu was opened on (a block entity, a mob, a pouch in a slot); None for the player's own and a crafting table's. source
  • .group(name: &str) -> SlotGroup<'_>Slot group name of this menu; asking for one it doesn't have is a mistake that gets logged, and the group is empty. source
  • .find_group(name: &str) -> Option<SlotGroup<'_>>group, when not having it is fine. source

#

How a part is laid out and shown: the same properties the engine's own screens use. Sizes are GUI pixels; None = fit content.

  • .row() -> S source
  • .column() -> S source
  • .tooltip(key: &str) -> SA tooltip over the part (a translation key, with all of rich text). source
  • .tooltip_args(key: &str, args: &[Arg]) -> S source
  • .class(class: &'static str) -> S source
  • .h(h: f32) -> S source
  • .w_pct(p: f32) -> S source
  • .h_pct(p: f32) -> S source
  • .min_w(w: f32) -> S source
  • .min_h(h: f32) -> S source
  • .max_w(w: f32) -> S source
  • .self_align(a: u32) -> SIts own place across its parent (abi::ui_align). source
  • .scroll(mut self) -> SChildren scroll (mouse wheel) and are clipped to the part, with a bar when longer. source
  • .no_wrap(mut self) -> SText on one line. source
  • .mono(mut self) -> SText with every glyph in a digit-wide cell, so changing numbers don't move what follows ({mono}..{/mono} does it for a part of a text). source
  • .scale(s: f32) -> SText size (2 for a screen's title). source
  • .disabled(yes: bool) -> SA button that can't be pressed now. source
  • .selected(yes: bool) -> SA button shown as the chosen one (the open tab). source
  • .gap(g: f32) -> S source
  • .pad(p: f32) -> S source
  • .size(w: f32, h: f32) -> S source
  • .w(w: f32) -> S source
  • .grow(mut self) -> S source
  • .center(mut self) -> S source
  • .stretch(mut self) -> SChildren fill the cross axis (rows as wide as the column), so spacer()s can center. source
  • .end(mut self) -> S source

  • .set(key: &str, args: &[Arg]) source
  • .text(text: &str)Ready text, shown as it is (not a translation). source

#

  • .view() -> ClientView source
  • .column(s: S, f: impl FnOnce(&mut Ui)) source
  • .row(s: S, f: impl FnOnce(&mut Ui)) source
  • .panel(class: &str, s: S, f: impl FnOnce(&mut Ui))A background of class class (gui/<class>.png, e.g. "panel"). source
  • .text(key: &str)Translated text. source
  • .text_args(key: &str, args: &[Arg]) source
  • .text_styled(s: S, key: &str, args: &[Arg])Text with a class, size, one line, mono...: ui.text_styled(S::column().class("title").scale(2.0), "mymod.title", &[]). source
  • .text_bind(f: impl Fn(&ClientView, &mut TextOut) + Send + Sync + 'static)Text recomputed every frame; redrawn only when it changes. source
  • .text_bind_styled(s: S, f: impl Fn(&ClientView, &mut TextOut) + Send + Sync + 'static) source
  • .screen_parts(screen: &str, area: &str)What mods add to place area of a screen or HUD element (Registry::screen_part). A screen of your own that replaces an engine one (core:title) keeps other mods' buttons by building its places. source
  • .recipe_inputs()In a recipe kind's display: the recipe's inputs as the kind's grid. source
  • .recipe_outputs() source
  • .recipe_input(i: u32)Only input i, for layouts that place them apart. source
  • .recipe_output(i: u32) source
  • .group(name: &str)Every slot of the menu's group name (MenuBuilder::group), laid out as its grid. source
  • .group_slot(name: &str, i: u32)Only slot i of group name, for layouts that place a group's slots apart. source
  • .player_inventory(title: bool)The player's inventory and hotbar (MenuBuilder::player_inventory), spaced like vanilla, under the title "Inventory" when title. source
  • .title()The open menu's title: what a player named the furnace or chest, else the name of the block it was opened on, else the translation menu.<ns>.<name>. source
  • .equipment()The player's equipment slots of a menu with .equipment(), in a column. source
  • .recipe_arrow()The arrow of a menu that makes recipes (.recipes(..) on the menu): clicking it opens them in the recipe viewer. Empty, for a crafting grid. source
  • .recipe_arrow_bind(f: impl Fn(&ClientView) -> f32 + Send + Sync + 'static)recipe_arrow showing progress (a furnace's cooking). source
  • .progress_bind(class: &str, s: S, f: impl Fn(&ClientView) -> f32 + Send + Sync + 'static)Progress from any value 0..1; a negative one hides it, like icons. source
  • .progress_bind_dir(class: &str, s: S, dir: u32, f: impl Fn(&ClientView) -> f32 + Send + Sync + 'static)Like progress_bind, filling in direction dir (abi::ui_dir). source
  • .icons(class: &str, count: u32, f: impl Fn(&ClientView) -> f32 + Send + Sync + 'static) -> Icons<'_>count icons showing a value in half-icon steps (hearts, hunger); a negative value hides them. source
  • .image(texture: &str, w: f32, h: f32) source
  • .player_model(w: f32, h: f32)The local player's model with what it wears. source
  • .spacer() source
  • .button(key: &str, s: S, f: impl Fn(&ClientView) + Send + Sync + 'static) source
  • .button_double( &mut self, key: &str, s: S, f: impl Fn(&ClientView) + Send + Sync + 'static, double: impl Fn(&ClientView) + Send + Sync + 'static)A button that does something more when clicked twice in a row (a world in a list: once selects, twice plays). source
  • .icon_button(texture: &str, w: f32, h: f32, s: S, f: impl Fn(&ClientView) + Send + Sync + 'static)A button showing a picture (a texture like image's, "mymod:gui/sort", w by h GUI pixels) and nothing else: what it does goes in its tooltip (S::tooltip). source
  • .button_args(key: &str, args: &[Arg], s: S, f: impl Fn(&ClientView) + Send + Sync + 'static)A button whose label has arguments (settings.gui_scale with the scale). source
  • .input(value: &str, max: u32, s: S, on_change: impl Fn(&ClientView, &str) + Send + Sync + 'static)A one-line text field starting with value (at most max characters, 0 for any); on_change gets the text after every edit. source
  • .slider( &mut self, s: S, value: impl Fn(&ClientView) -> f32 + Send + Sync + 'static, on_change: impl Fn(&ClientView, f32) + Send + Sync + 'static)A slider at value (0..1, read every frame); on_change gets where the player drags it. source
  • .item(item: u32, count: u32, s: S)An item's icon, with count under it when above 1. source
