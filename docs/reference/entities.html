#

  • .modifier(m: crate::Modifier)An attribute modifier its entities have, .when(..) while conditions hold (Modifier). source
  • .attach<T: Value>(component: &Component<T>)Every entity of this kind carries component (declared with r.entity_component, by any mod), starting at the kind's own value of it (.set), else its declared one; another mod's kind with r.edit(&PLAYER).attach(..). Not .set: that is one value of the kind itself, .attach gives each entity its own, which changes. source
  • .attach_with<T: Value>(component: &Component<T>, value: T)attach with another starting value. source
  • .attach_storage(storage: &Storage)Every entity of the kind carries storage (declared with r.storage), empty at first. source
  • .solid()A solid body: others stand on it and ride along, bump into it and get pushed by it (platforms, boats, lifts). Not pushed around itself. source
  • .invulnerable()Takes no damage (no hurt flash, health stays); /clear and the void still remove it. source
  • .unpushable()Neither pushes nor is pushed by other entities (ghosts, projectiles). source
  • .kinematic()Moved exactly by the velocity mod logic gives it (entity_modify), through blocks, no gravity: lifts, airships, contraptions. source
  • .hazard(h: crate::Hazard)What it does to entities: itself (Hazard::own) or what it squeezes (Hazard::crushed). source
  • .crushing()A solid body that hurts what it squeezes into blocks instead of only pushing it. source
  • .burns_in_sun()Daylight from an open sky sets it burning for 8 seconds, as the undead in vanilla, unless it wears something on its head. source
  • .carry_height(blocks: f32)Riders up to blocks above the body (jumping, flying around inside it) keep moving with it and their own motion stays relative to it, so a jump on a fast ship lands on the ship. source
  • .light_at(x: f32, y: f32, z: f32)Where the light it gives comes from: blocks from its feet, +Z ahead, turned with it (a lantern on its head). Its middle when not said, a block entity's block. source
  • .shown_slots(slots: &[u32])Slots of its inventory everyone around sees (what a pedestal holds): their items give their light, and clients read them as core:shown ([u32], 0 empty). source
  • .size(width: f32, height: f32) source
  • .eye_height(blocks: f32)Eye height in blocks, EYE_SHARE of its height when not said. source
  • .no_egg(mut self)No spawn egg. Every entity has one otherwise, <name>_spawn_egg, called after it and looking generic until item/<name>_spawn_egg.png exists: for what isn't a creature (a projectile, a moving platform). source
  • .own_effects()The client makes no steps, idle noises or death smoke for it: r.client_entity_frame does its effects instead. source
  • .effect(event: &str, sound: &str, particle: &str)What event (hurt, death, ambient, step) sounds and shows instead of its .sound(..) and the engine's (smoke when it dies): a sound event and a particle kind, "" for what it would be anyway, "none" for nothing. source
  • .equipment()It has the player's equipment slots (Registry::equipment_slot) after its own: what it wears shows on its model and counts like a player's armor; group(EQUIPMENT_GROUP) or a slot's name in w.inventory(id) reaches them. source
  • .poses()It takes the poses the player does, by the keys its walk holds (Walk) and the poses' conditions: crouches, swims lying down, crawls where nothing higher fits. source
  • .picks_up_items()It picks up the dropped items it touches into its inventory, as the player does. source
  • .attack_damage(damage: f32)Its own melee damage (World::attack), the base of its attribute::ATTACK_DAMAGE; what it holds adds to it, as vanilla's. source
  • .attack_speed(per_second: f32)Its melee hits per second (1), like an item's; attribute::ATTACK_SPEED multiplies it. source
  • .reach(blocks: f64)How far it hits (the ENTITY_REACH attribute, from its eyes to the target's box); a modifier changes it like any attribute. source
  • .max_health(h: f32) source
  • .attribute(a: &crate::Attribute, v: f64)The kind's own base of an attribute: .attribute(&attribute::GRAVITY, 0.625) falls like vanilla's arrow. source
  • .projectile(p: Projectile)It flies as a projectile (Projectile): the engine moves it, a ray along its speed each tick decides what it hits (actions::PROJECTILE_HIT), however fast. source
  • .hitboxes(h: Hitboxes)What hits land on, part by part (Hitboxes::humanoid() ...); without, its whole box. source
  • .walk_speed(s: f32) source
  • .category(category: &EntityCategory)A category registered with Registry::entity_category (any mod's), for spawn caps and despawning. source
  • .hostile() source
  • .passive() source
  • .texture(t: &str)Skin texture under entity/; without this, the kind's name (entity/zombie). source
  • .model(model: impl Into<Model>)A model built in code (humanoid(..), quadruped(..), spider(), or parts of your own). source
  • .sound(event: &str)Sound event event (hurt, death, ambient, step): one of the files sounds/entity/<kind>/<event>*.ogg|wav at random. source
  • .sound_variants(event: &str, files: &[&str])Sound event event from these files of sounds/entity/<kind>/, one at random. source
  • .sound_group(group: &str)Sounds from <ns>:entity.<group> (.hurt, .death, .ambient, .step events); a name with a namespace is used as it is. source
  • .animations(name: &str)Keyframe animations from animations/<name>.animation.json: idle and walk play by themselves, others with World::action_play. A file named like the kind is used even without this. source
  • .body(template: &crate::Template)A moving body built of template (Registry::template; block (0, 0, 0) is centered on the entity's position, its box is what the blocks fill). Blocks are placed and broken on it like in the world, and it carries what stands on it; usually .solid(). source
  • .shader(shader: &crate::Shader)Shades the model with shaders/entity/<name>.wgsl. source
  • .on_tick(f: impl Fn(&EntityTick) + Send + Sync + 'static)Called once per tick with every entity of this kind. source
  • .goals(goals: crate::ai::Goals)Behavior from goals and what sets it off (ai::Goals), run every tick; replaces on_tick. source
  • .on_hurt(f: impl Fn(&World, &crate::Hurt) + Send + Sync + 'static)One of these was hurt: actions::HURT for this kind, after the damage, with the other events at the end of the tick. Changing the damage is r.modify(&chain::DAMAGE, ..), preventing it r.before_event(&actions::HURT, ..). source
  • .on_died(f: impl Fn(&World, &crate::Death) + Send + Sync + 'static)One of these died: actions::DIE for this kind. source
  • .on_interact(f: impl Fn(&mut EntityEvent) -> bool + Send + Sync + 'static)A player right clicked one, and actions::INTERACT_ENTITY let it; true if it did something, which swings the player's arm. source
  • .seat(seat: crate::riding::Seat)A place to ride it, in the order seats are numbered (crate::riding::Seat). source
  • .steering(s: crate::riding::Steering)How the keys of a player in a seat that steers move it (steer::*, or your own). source
  • .rider_rules(rules: crate::riding::RiderRules)What its riders may do (RiderRules). source
  • .riders_fall()Its falls hurt its riders too, as a horse's. source
  • .ride_camera(blocks: f32)Blocks the third-person camera stays further back while riding it, 0 for none; without this, by its size. source
  • .rideable()A right click gets on it, in its first free seat (on_interact doing w.mount). source

#

What hits land on, part by part (EntityBuilder::hitboxes): boxes in pixels (1/16 block, its feet at 0, -Z its front, -X its right) at the kind's size; one made bigger is hit bigger. Rays, arrows and blows tell the part they hit (RayHit::part, Damage::part, the part a chain step reads in its query). They go with the body, a head with the look, arms and legs swing as it walks: run and an arrow may pass between them. Not the model's boxes: how a mob looks never changes where it can be hit.

  • .new() -> Hitboxes source
  • .part(name: &str, min: [f32A part going with the body. source
  • .head(name: &str, min: [f32A head: it turns with the look about pivot, its neck. source
  • .limb(name: &str, min: [f32A leg or an arm: it swings about pivot as it walks, swing radians at a full stride, phase radians after the beat (PI the other half of the step). source
  • .humanoid() -> HitboxesTwo legs, two arms, a body and a head, 32 pixels tall: the player's. source
  • .quadruped() -> HitboxesA body on four legs with a head ahead, 25 pixels tall: a cow's. source
  • .reaching(mut self)Its arms held out ahead, not swinging, as a zombie's. source
  • .slim(px: f32)Arms and legs px pixels thick, as a skeleton's. source

#

A model part (a bone): its name, pivot, boxes, free-form triangles, and the part it hangs from. The name says how it moves by itself, like in Blockbench's Bedrock models: head looks around, rightArm, leftArm, rightLeg, leftLeg swing while walking (arms resting held out, like a zombie's, only sway), body leans when sneaking, leg0..leg3 are a quadruped's and leg0..leg7 a spider's sweeping legs; other names keep still. Keyframe animations address bones by the same names.

  • .new(name: &str, pivot: [f32 source
  • .rotation(x: f32, y: f32, z: f32) -> ModelPartResting rotation in degrees about x, y, z (applied in that order). source
  • .cuboid(origin: [f32Box relative to the pivot in model pixels, uv = top-left texel of its unwrap. source
  • .inflated(by: f32) -> ModelPartThe last box grown by this much on every side, its texture staying the same (wool, a skin's outer layer). source
  • .mirrored(mut self) -> ModelPartThe last box's unwrap mirrored left to right. source
  • .child_of(index: usize) -> ModelPartHangs from the part at index in the same model: moves and turns with it. source
  • .mesh(triangles: Vec<abi::MeshVertex>) -> ModelPartFree-form triangles (three corners each), in model pixels like the pivot. source

  • .sticks(ticks: u32)It stays stuck where it hits a block, for ticks (vanilla's arrow a minute). source

#

When a mob reacts: what sets it off, at whom, and while what holds.

  • .sight(range: f64) -> TriggerSomeone within range blocks (8 up and down), as near as their visibility makes them; it goes on as long as they are. source
  • .gaze(range: f64) -> TriggerSomeone within range looking at it, with nothing in between (an enderman). source
  • .hurt() -> TriggerSomeone hurting it. source
  • .when(range: f64, test: impl Fn(&World, &EntityState, &EntityState) -> bool + Send + Sync + 'static) -> TriggerSomeone within range for whom test(world, the mob, them) holds. source
  • .only_if(f: impl Fn(&World, &EntityState) -> bool + Send + Sync + 'static) -> TriggerOnly while f(world, the mob) holds: a spider out of the daylight. source
  • .only_while(c: crate::Cond) -> TriggerOnly while c holds where the mob is (!Cond::new("day")). source
  • .of(kind: &'static EntityKind) -> TriggerNotices mobs of kind instead of players (a wolf and sheep). source
  • .of_tag(tag: &'static crate::Tag) -> TriggerNotices entities of kinds with tag instead of players (#undead). source
  • .of_any(pick: impl Fn(&World, u64, &EntityState) -> bool + Send + Sync + 'static) -> TriggerNotices whatever pick(world, id, state) accepts instead of players, them included or not. source
  • .by_anything(mut self) -> TriggerFor hurt: whatever hurts it, other mobs and the world too. source

One tick of a mob's walking for World::walk: a direction and the keys a player would hold.

  • .toward(dir: [f32Toward dir (x, z, length up to 1) at speed times its kind's walking speed. source
  • .jump()Jumps; swims and flies up. source
  • .sneak()Never steps off an edge, holds on to ladders, crouches; flies down. source
  • .sprint()Faster, a longer jump, swims lying down in a liquid it swims in. source
