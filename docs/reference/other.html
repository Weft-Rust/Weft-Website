#

A named contribution. Public fields are available through Deref for arbitrary mod code.

  • .new(name: &str)Starts an empty contribution; only explicitly selected fields participate. source
  • .priority(priority: i32)Higher priorities apply later. Equal priorities are ordered by source identity. source
  • .when(condition: &str)Activates while this condition holds at the chosen observation point. source
  • .blend(mode: u32)One of REPLACE, ADD, MULTIPLY or MAX, also used for named shader/object weights. source
  • .fade(enter: f32, leave: f32)Real seconds to reach full weight, or to disappear after removal/condition failure. source
  • .observer(point: u32)CAMERA by default; BODY samples the local player's eyes, even with a detached camera. source
  • .radius(inner: f32, outer: f32)An entity-centered zone, full inside inner and zero outside outer, linear between. source
  • .around(center: [f64A fixed zone instead of following the entity that owns it. source
  • .fog(rgb: u32, start: f32, end: f32)Absolute fog color (0xRRGGBB) and explicit start/end distances in blocks. source
  • .sunlight(strength: f32)Sky illumination, cloud lighting and directional sunlight, independent of sky-object visibility. source
  • .sky_color(rgb: u32)Absolute sky color (0xRRGGBB), independent of illumination. source
  • .cloud_color(rgb: u32)Cloud tint (0xRRGGBB) before lighting, replacing the time/weather tint. source
  • .cloud_fog(start: f32, end: f32)Cloud fog start/end in blocks from the camera, independent of world fog. Zero end hides clouds. source
  • .sky_opacity(opacity: f32)Visibility of the complete sky, including clouds. source
  • .sky_object(object: &crate::SkyObject, opacity: f32)Visibility of a dimension-qualified object (DIM.sky(&SUN)), including sunset glow. source
  • .acoustics(cutoff_hz: f32, reverb: f32, volume: f32)World low-pass cutoff in Hz, linear reverb send and linear volume gain. source
  • .overlay(texture: &str, opacity: f32)Appends a screen texture; relative paths start at this mod's textures directory, without .png. source
  • .post(shader: &crate::Shader, strength: f32)Adds a named post shader at this strength. source
  • .replace_overlays(mut self)Crossfades out preceding overlays, even when this layer adds none. source
  • .replace_post(mut self) source

The completed stages before this callback, plus its own earlier writes. Reads in the same stage never depend on another start's execution order. This view cannot outlive the callback it was borrowed from.

  • .read(pos: impl Into<BlockPos>) -> u32A state at any world coordinate, including across cube boundaries; air outside the dimension. source
  • .column(x: i32, z: i32) -> ColumnThe terrain's reference height and biome. This is metadata, before features change blocks. source
  • .find(from: impl Into<BlockPos>, dir: Dir, distance: u32, mut test: impl FnMut(u32) -> bool) -> Option<BlockPos>First cell matching test, starting at from, then at most distance steps in dir. source
  • .all(from: impl Into<BlockPos>, to: impl Into<BlockPos>, mut test: impl FnMut(u32) -> bool) -> boolEvery cell in the box between two opposite corners matches test. source
  • .surface_block(x: i32, z: i32) -> u32What is now at the terrain's reference surface; air where it was carved away. source
  • .surface_carved(x: i32, z: i32) -> boolWhether the terrain's reference surface is now empty. source
  • .fit(x: i32, z: i32, size: impl Into<BlockPos>, max_slope: i32) -> Option<BlockPos>Fits a footprint at the terrain's reference height, rejecting missing ground and steep slopes. source
