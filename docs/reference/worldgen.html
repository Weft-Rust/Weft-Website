#

Where a biome stands in a terrain. Its climate and surface come from the biome (r.biome(&X).temperature(..).surface(..)); a rule adds where else it must hold (height, continent, any field) and sets only what differs here. Rules are tried in order; the first match wins and the last one is used where none does.

  • .new(biome: &str) -> BiomeRuleA rule for biome, named like it. source
  • .named(name: &str)A name of its own, for a second rule of the same biome (other mods find rules by name). source
  • .biome(biome: &str)In an edit: the rule picks this biome instead. source
  • .field(name: &str, range: impl RangeBounds<f64>)Where the field (temperature, humidity, continent or one the terrain declares) is in range, like 0.35.. or ..-0.45 (from inclusive, to exclusive). Given again for the same field, the new range replaces the old. source
  • .temperature(range: impl RangeBounds<f64>)Climate, about -1.4..1.4. Usually the biome's. source
  • .humidity(range: impl RangeBounds<f64>) source
  • .continent(range: impl RangeBounds<f64>)Continentalness: below 0 is sea, coasts are about 0..0.1. source
  • .height(range: impl RangeBounds<i32>)Surface heights, like ..=SEA + 1. source
  • .surface(top: &str, filler: &str, depth: i32)Top block, then depth blocks of filler, then the terrain's stone. source
  • .under(block: &str, layers: i32)The lowest layers of the filler become block (sandstone under sand). source
  • .deep_top(block: &str, below: i32)Top block for columns lower than below (gravel on deep sea floors). source
  • .bare_above(y: i32)Plain stone above this height (bare peaks). source
  • .frozen(block: &str)The water surface freezes into block. source

#

A number for every column of a terrain, worked out from where the column is: the height a landform adds, the strength of a mask, a field biome rules ask for. Built from numbers, the position and noise with +, -, * and the methods here; the engine runs it on the CPU and the GPU with the same integer math, so every machine gets the same world.

  • .value(v: f64) -> ExprA plain number. source
  • .blocks(b: f64) -> ExprA length in blocks. source
  • .int(n: i32) -> ExprAn integer as it is, for idiv and modulo by a count. source
  • .x() -> ExprThe column's position, a length. source
  • .z() -> Expr source
  • .field(name: &str) -> ExprA field of the terrain: temperature, humidity, continent, or one declared with TerrainBuilder::field before what uses it. Worked out once per column however many times it is used, so share costly parts through a field. source
  • .temperature() -> ExprAbout -1.4..1.4, cold to hot. source
  • .humidity() -> ExprAbout -1.4..1.4, dry to wet. source
  • .continent() -> ExprContinentalness: below 0 is sea, coasts are about 0..0.1. source
  • .fbm(salt: u64, scale: f64, octaves: u32) -> ExprNoise about -1..1 in patches about scale blocks across, octaves layers of it each twice as fine and half as strong. Noises with the same salt and size line up. source
  • .noise(scale: f64) -> Exprfbm of 3 octaves with a salt of its own size. source
  • .ridge(salt: u64, scale: f64) -> Expr1 along lines where the noise crosses 0, falling to 0 a quarter of the way to its peaks: winding ridges or cuts scale blocks apart. source
  • .sites(salt: u64, spacing: f64, chance: f64, radius: f64) -> ExprPoints scattered one per spacing x spacing square at most, each there with chance and radius blocks big times 0.5 to 1.5: the square of the distance to the nearest, in units of its radius (below 1 inside it), 2 or more where none is near. source
  • .at(x: Expr, z: Expr) -> ExprThis expression at another position: noise.at(Expr::x() + warp, Expr::z()) bends it. Fields stay what they are at the column. source
  • .abs() -> Expr source
  • .min(other: Expr) -> Expr source
  • .max(other: Expr) -> Expr source
  • .clamp(lo: Expr, hi: Expr) -> Expr source
  • .idiv(other: Expr) -> ExprInteger division, toward zero: a length by Expr::int(2) is half as long. source
  • .modulo(other: Expr) -> ExprWhat is left over below other (a length or a count), never negative: repeats along the world. source
  • .ramp(from: f64, to: f64) -> Expr0 at from, 1 at to and straight in between, a strength for a mask; from > to turns it around. source
  • .ramp_blocks(from: f64, to: f64) -> Exprramp of a length, from and to in blocks. source
  • .not() -> Expr1 minus it, for masks. source
  • .and(other: Expr) -> ExprBoth masks: their product. source
