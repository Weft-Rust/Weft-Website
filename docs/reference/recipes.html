Recipes and loot reference

On this pageLootBuilderPoolRecipeBuilderRecipeKindBuilderRecipeView

Recipe kinds, recipes, loot tables and their pools.

#

A loot table being registered (Registry::loot) or changed (r.edit(ZOMBIE.loot())); sent when dropped.

  • .pool(p: Pool)One more pool, after the table's. source
  • .replace_drop(from: &str, to: &str)Every entry of item from gives to instead, in whatever pools the table has in the end. source
  • .remove_drop(item: &str)Entries of item are left out, likewise. source
  • .clear()Empties the table, its swaps too; pools added after it stay. source

#

Rolls (1 by default) of one weighted choice each.

  • .new() -> Pool source
  • .rolls(min: u32, max: u32) -> Pool source
  • .when(c: impl Into<Cond>) -> Pool source
  • .entry(e: Entry) -> Pool source
  • .item(name: &str) -> PoolOne of name. source
  • .items(name: &str, min: u32, max: u32) -> Poolmin..=max of name. source

#

  • .named(name: &str)Its name instead of <mod>:<kind>/<output>. source
  • .input_amounts(counts: &[u32])How many of each input it takes, in the order of the inputs (millibuckets for liquids). source
  • .output(item: &str, count: u32)Another result (an item, or a liquid by its name and millibuckets). source
  • .output_chance(item: &str, count: u32, chance: f32)A result that comes out with chance chance (0..1) each time: a pool of it and nothing. source
  • .extra(pool: crate::Pool)Rolls of more results, as a loot table's (r.loot(..).pool(..)). source
  • .keep(key: impl RecipeSlot)Works, but the recipe viewer doesn't list it. Ingredient key (its pattern character, or for a recipe without a pattern its place among the inputs) stays as it is: a mold, a catalyst. source
  • .wear(key: impl RecipeSlot, amount: u32)Ingredient key stays and wears by amount a run, breaking when it is worn out: a hammer. source
  • .leaves(key: impl RecipeSlot, item: &str)Ingredient key is used up and item takes its place (any mod's): a lava bucket leaving its bucket. Without this one leaves its item's remainder. source
  • .hidden() source

#

A recipe kind being registered; sent when dropped.

  • .inputs(cols: u32, rows: u32)The recipe viewer shows inputs as a grid this big, whatever a recipe uses (a crafting table's 3 x 3). source
  • .outputs(cols: u32, rows: u32) source
  • .info_line(key: &str, values: &[&str])A line under each recipe: translation key, its {0}.. filled with values: time (seconds) or components the recipe carries (mymod:energy_per_tick). source
  • .layout(f: impl Fn(&mut Ui, &RecipeView) + Send + Sync + 'static)Builds each recipe yourself instead of the usual inputs, arrow, outputs: ui.recipe_inputs(), ui.recipe_outputs() and ui.recipe_input(i) place its slots. source

#

One recipe of a kind, found by recipe_find (or shown by a kind's layout).

  • .time() -> u32Its time in ticks. source
  • .outputs() -> Vec<(ItemStack, f32)>Its results with their chances; a liquid's is its item by the millibucket. source
  • .roll(w: &crate::World) -> Vec<ItemStack>What else one run of it gives this time, its pools rolled. source
  • .value<T: Value, K>(comp: &Component<T, K>) -> Option<T>A value the recipe carries (r.shaped(..).set(&COMP, v)): its entry's. source
  • .consume(stacks: &mut [ItemStack]) -> boolTakes its inputs out of stacks (the ones recipe_find was given); false, and nothing taken, if they are not all there. source
