Blocks reference

On this pageBlockBuilderHazardLiquidBuilderPropsReactionBuilderRule

The block builder and everything a block's rules, hazards and states are made with.

#

  • .prop(name: &str, values: impl PropValues)A named property with its values, the first being the default: .prop("lit", ["false", "true"]), .prop("age", 0..=7). The block has a state for every combination of its properties; read and change them with World::prop / prop_set. An edit adds it. source
  • .states(f: impl for<'s> Fn(&Props, State<'s>) -> State<'s> + 'static)Customizes each state by its property values, on top of the block's own settings: .states(|p, s| if p.is("lit", "true") { s.light(13) } else { s }). Its own properties only (an edit's: those it adds). source
  • .state_where(key: &str, f: impl for<'s> FnOnce(State<'s>) -> State<'s> + 'static)Changes the states key picks (prop=value,..: those with every value it names), any mod's properties: r.edit(&base::FURNACE).state_where("lit=true", |s| s.light(15)). On top of .states(..). source
  • .mined_by(class: &str, level: u32)Tools of class (tools/<class> items) mine it at their speed (tag mineable/<class>), and it drops nothing unless mined by one of at least level (tool_tier; HAND: drops anyway). The level is the harvest_level component, checked by Cond::harvested. source
  • .shader(shader: &crate::Shader)Shades its textures with a shader handle (Shader::named("stripes"), the file shaders/block/stripes.wgsl): the shader goes with the textures, so blocks sharing one share it. source
  • .tab(tab: &CreativeTab)Creative inventory tab of the block's item, see Registry::creative_tab. source
  • .no_tab()Its item is in no creative tab (.untag(abi::comp::NO_TAB) brings it back). source
  • .sound_group(group: &str)Sounds from the group <ns>:block.<group> (.break, .place, .step, .hit events); a name with a namespace is used as it is (base:block.stone from another mod). source
  • .drops(item: &str, count: u32)Its loot table: count of item when harvested (Cond::harvested). Without it the block drops its own item the same way; r.loot(&BLOCK) writes any other table. source
  • .drops_nothing(mut self)An empty loot table. source
  • .item_texture(t: &str)The block's item shows this flat texture from item/ instead of the block model. source
  • .no_item(mut self) source
  • .retexture(from: &str, to: &str)In an edit (Registry::edit): block texture from (another mod's, base:torch) becomes to on its states, and the item texture of that name too. source
  • .grows(mean_seconds: f32, min_light: u32)Grows over time, a step every mean_seconds on average (spread like random ticks) while the light is at least min_light: by default to the next state until the last. Timed by world time, so unloaded plants catch up when their area loads again. A rule (Rule::random(..).grows()). source
  • .needs_near(what: &str)The block it stands on must have one what takes beside it (a block matcher, sugar cane: #water), unless that is this same block. source
  • .on_grow(f: impl Fn(&mut BlockEvent) + Send + Sync + 'static)What a growth step does instead of moving to the next state (growing a tree, a block on top); it keeps growing as long as the block stays. source
  • .spreads(to: &str, mean_seconds: f32, min_light: u32)Spreads onto blocks to takes near it (a block matcher, grass onto #grass_spreads_to): a target within 1 block sideways, 3 down and 1 up with min_light above it and nothing opaque on top turns into this block in mean_seconds on average (sooner with more of this around), also while nobody is near (caught up on loading). source
  • .spread_when(when: impl Into<crate::Cond>)What has to hold for a target of spreads instead (moss up a wall: Cond::new("light(9.., any)"), covered or not). source
  • .spread_reach(min: impl Into<BlockPos>, max: impl Into<BlockPos>)Where spreads reaches, from this block to the target: min and max offsets, at most 4 each way (grass: [-1, -3, -1] to [1, 1, 1], the default). source
  • .smothered_into(block: &str, mean_seconds: f32)Turns into block in mean_seconds on average once something opaque covers it (grass into dirt). source
  • .ambient_particle(kind: &str)Particles of kind clients show around it now and then, near the player (vanilla's torch smoke, a crystal's sparks). A kind nothing registers is a load error. source
  • .ambient_particles(kinds: &[&str])Like ambient_particle with several kinds at once (a torch's flame and smoke). source
  • .on_use(f: impl Fn(&mut Use) -> bool + Send + Sync + 'static) source
  • .on_place(f: impl Fn(&World, &crate::BlockChange) + Send + Sync + 'static)One of these was placed: actions::PLACE_BLOCK for this block, at the end of the tick. source
  • .on_break(f: impl Fn(&World, &crate::BlockChange) + Send + Sync + 'static)One of these was broken, by a player (player) or by losing its support (0). source
  • .on_neighbor(f: impl Fn(&mut BlockEvent) + Send + Sync + 'static) source
  • .joins(sides: crate::Facings, to: &str)A true/false property for each of sides (north, east .. up, down) kept saying whether the block there is one to takes (a block matcher: #fences, another mod's pipes by a shared tag, its own name). Fences, walls, panes, pipes and cables: .states shapes it by p.is("north", "true"). source
  • .derived(prop: &'static str, f: impl Fn(&Neighbors) -> &'static str + Send + Sync + 'static)Property prop worked out from the blocks around, kept up to date by the engine as they change (a stair's corner shape). f gives the value; the property must have it. source
  • .on_carried(f: impl Fn(&mut BlockEvent) + Send + Sync + 'static)On a moving body, it came to another cell of the world: a drill, a plow. pos is that cell, in the world's coordinates; body_pos where this is on the body, entity the body. source
  • .on_scheduled(f: impl Fn(&mut BlockEvent) + Send + Sync + 'static) source
  • .falling()Falls like sand when nothing holds it up: a block next to it changing checks two ticks later whether below is free, and if so it drops as a moving block (World::fall_block). source
  • .entity(f: impl for<'r> FnOnce(crate::EntityBuilder<'r>) -> crate::EntityBuilder<'r> + 'static)Each placed block gets a block entity, an invisible entity of a kind named like the block that comes and goes with it: data of its own (e.attach(..), ticked by a system), a model, items (e.inventory(27)). Doesn't make it usable: that is opens or on_use. .entity(|e| e.attach(&SPEED)). Its items drop when it breaks. source
  • .opens(menu: &crate::Menu)Using it opens menu, on its block entity if it has one (a furnace), else on nothing (a crafting table). A menu with .recipes(..) makes the block a station of those recipes in the recipe viewer. source
  • .sneak_use(rule: u32)Whether a sneaking player uses it (abi::sneak_use): without, as vanilla, only with empty hands, what is held going first otherwise (a block placed against a chest). ALWAYS calls on_use with sneaking set, and it passes the click on with handled = 0. source
  • .facing(allowed: crate::Facings, toward: crate::Toward)A facing property with the directions in allowed (p.facing() in .states), set by toward when placed: three allowed directions are three values. Its model, written facing north, turns to it (Orientation::front) unless a state says otherwise. source
  • .axis(mut self)An axis property (y, x, z), set along the face clicked, its model written standing up and laid that way (a log): p.get("axis") in .states. source
  • .default_facing(d: crate::Dir)Which way it faces as an item and by default (after facing). source
  • .wire(mut self)Wire that lies on any face of a block, connecting to wire of the same block only; textures are the dot on top and the line on the sides. It lies on sides of its cell like on_sides (west..south properties). source
  • .signal_constant()Always gives full power to what is next to it. source
  • .signal_switch()A lever or button: goes on the clicked face; its power property (off, on) gives full power around it and strongly into the block it is on. source
  • .signal_torch()Goes on the clicked face and gives full power unless the block it is on has any. source
  • .signal_repeater()Goes on the clicked face; full power out of the front, a delay property (1..4 redstone ticks, two game ticks each) after what is behind it has any. source
  • .signal_comparator()Goes on the clicked face; out of the front what is behind it, unless a side has more. Its mode property (compare, subtract) takes the sides from it instead. source
  • .signal_observer()A pulse out of its back when the block at its facing changes (after facing). source
  • .signal_sink()Its power property, if it has one, and on_signal follow the power around it. source
  • .signal_read(f: impl Fn(&World, BlockPos) -> u8 + Send + Sync + 'static)What a comparator behind it reads, 0..15, instead of how full it is. It looks again when the block changes; for anything else it depends on, call World::signal_read_changed. source
  • .signal_floater(breaks: bool)Goes along its facing (after facing), any of the six ways. Its front is what sticks: with power from any other side it carries itself, the block in front of it and what is stuck to that the way slime does, half a block a second per level of power. Circuits on it go on. Without power, or against what it can't go through, it all lands on a whole block. power: 0 idle, 1 going, 2 stuck. breaks: it breaks what is in its way instead. source
  • .signal_piston(head: &'static str, sticky: bool)Pushes blocks at its facing with power from any other side (after facing). Its power property: off in, moving while its head is on the way, on out, the head being the state's own cell in front (.cells). head: what the head looks like on the way, a block with a facing property that is never in the world. sticky brings a block back. source
  • .signal_piston_head()A piston's head on its way (after facing), drawn by the body moving it. source
  • .signal_gate(gate: Gate, f: impl Fn(&GateInputs) -> u8 + Send + Sync + 'static)A gate with logic of your own, on the clicked face: what comes out of its outputs a gate's delay after what goes in at its inputs calls for it. Runs only when something around it changes. source
  • .on_signal(f: impl Fn(&SignalEvent) + Send + Sync + 'static)Called when the power around a signal_sink changes. source
  • .merge(f: impl Fn(&Place, &mut Props) + Send + Sync + 'static)Its own item placed in its cell: .merge(|p, props| props.set("type", "double")) takes the item in, with props those of what is there and p.placed("type") how the item would go; leaving them as they are places it as usual. source
  • .shares_cell_with(what: &str)What may be in one cell with it though their shapes overlap (a block matcher): snow on a plant, #water for a source of water to stay in it and a bucket to fill it (a liquid fills its whole cell). Blocks whose shapes don't overlap share a cell without asking. source
  • .placement(f: impl Fn(&Place, &mut Props) + Send + Sync + 'static)Chooses property values when a player places it (after facing): .placement(|p, props| props.set("axis", if p.face().horizontal() { "x" } else { "y" })). source
  • .on_sides(allowed: Facings)A layer one pixel thick against sides of its cell (vines, ladders, glow lichen, a wall sign's plate): a property per side in allowed (north .. down, "true" where it lies). It goes against the face clicked, or the allowed side nearest the look when that one isn't; its own item put into its cell adds a side, up to every allowed one; a side with nothing solid behind it falls off, and breaking takes one side at a time. Redstone wire is the same with a drawing of its own. Facings::HORIZONTAL for ladders (walls only), Facings::ALL for vines everywhere. source

#

What a block, an entity kind or a dimension does to an entity meeting it (.hazard(..)): Hazard::touch(1.0, &CACTUS) a cactus, Hazard::on(1.0, &HOT_FLOOR) magma, Hazard::inside(1.0, &damage_causes::FIRE).fire(160) fire, Hazard::own(..) a kind's to itself or a dimension's to whoever is in it, Hazard::crushed(..) a body's to what it squeezes; .every(ticks) between hits, .when(..) conditions about the entity there.

  • .inside(damage: f32, cause: &crate::DamageCause) -> HazardIts box in the block's shape. source
  • .on(damage: f32, cause: &crate::DamageCause) -> HazardStanding on it. source
  • .head(damage: f32, cause: &crate::DamageCause) -> HazardIts eyes in it. source
  • .touch(damage: f32, cause: &crate::DamageCause) -> HazardWithin a sixteenth of its shape. source
  • .own(damage: f32, cause: &crate::DamageCause) -> HazardWherever it is, asked at its eyes: an entity kind's to itself, a dimension's to everyone in it (.when(..) says where: height(..0)). source
  • .crushed(damage: f32, cause: &crate::DamageCause) -> HazardA body of this kind squeezes it into something solid; the body crushes instead of pushing. source
  • .fire(ticks: u32) -> HazardSets it burning for that many ticks too. source
  • .harmless(mut self) -> HazardNo damage of its own: only fire. source
  • .every(ticks: u32) -> Hazard source
  • .when(c: impl Into<Cond>) -> Hazard source

#

A liquid: its block (16 states) and flow rules, optionally a filled bucket item. Its own components are its flow (comps::liquid); its block's (tags, particles) go in .block(..), and the block's tags are its item's too.

  • .block(f: impl for<'r> FnOnce(BlockBuilder<'r>) -> BlockBuilder<'r> + 'static)Its block, on top of what makes it a liquid (texture <name>_still, drawn solid like lava): .block(|b| b.tint(&tints::WATER).translucent().drag(0.4).light(15).tag("water")). In an edit, what it changes of the block (and the tags of its item). source
  • .flow_delay(ticks: u32)Ticks between flow steps (water 5, lava 30). source
  • .drop_off(n: u32)Level lost per block spread (water 1: 7 blocks, lava 2: 3 blocks). source
  • .slope_find(n: u32)How far it looks for a way down (water 4, lava 2). source
  • .renewable(sources: u32)New sources form where at least sources sources are beside a spot over solid ground (vanilla water 2). 0: always, one bucket fills everything up to its level; more than the sides there are: never, as without this call. source
  • .flows_up()Rises instead of falling. source
  • .heat(t: u32)Roughly Kelvin; 1000 and more burns what touches it. source
  • .fog(rgb: u32, start: f32, end: f32)A camera environment preset: color (0xRRGGBB), start and end in blocks. Defaults to the average texture color, start -8 and end 96. Acoustics are independent. source
  • .overlay(texture: &str, opacity: f32)The picture over the screen from inside, relative names are under block/, and how much of it shows. By default its own texture at 0.1; for an inside that looks unlike the surface, set this and fog apart from its texture. source
  • .no_overlay()Nothing over the screen from inside. source
  • .bucket(item: &'static Item, empty: &Item, tab: &CreativeTab)Also registers item: empty (a container item, any mod's) filled with this liquid, in creative tab tab (any mod's). The engine fills and pours it; no code needed. source

What happens where two liquids meet, named <mod>:<liquid>><touching> (base:hot>water) unless named.

  • .named(name: &str)Its name instead of <mod>:<liquid>><touching>. source
  • .source_turns_into(block: &str)What a source of the liquid becomes. source
  • .flowing_turns_into(block: &str)What flowing liquid becomes. source
  • .below_turns_into(block: &str)What the touched liquid becomes when this one flows down into it. source

#

What happens to a block by itself (.rule(..) on a block or a state): when (Rule::random(mean_secs) now and then, Rule::neighbor() as soon as something next to it changes, Rule::after(secs) that much later), if (.when(..), again for more, about its own cell and state), then (.becomes("age=0") or .becomes("base:dirt"), .grows(), .breaks(), .falls()). Time goes on in unloaded areas and is caught up when they load. grows, smothered_into, needs, falling are rules.

  • .random(mean_secs: f32) -> Rule source
  • .neighbor() -> Rule source
  • .after(secs: f32) -> Rule source
  • .when(c: impl Into<Cond>) -> Rule source
  • .becomes(into: &str) -> RuleProperties set (age=0) or another block (base:dirt, base:farmland[moisture=0]). source
  • .grows(mut self) -> RuleIts on_grow, else its age one higher. source
  • .sheds(into: &str) -> RuleA piece comes off: it becomes into (north=false), dropping what the piece drops. source
  • .breaks(mut self) -> RuleBreaks off, dropping what it drops. source
  • .falls(mut self) -> Rule source
