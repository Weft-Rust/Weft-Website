#

How a camera moves: called each frame on the client with the keys, the player's eyes and last frame's camera (CameraArgs), it sets out. It brings the tags it needs along (comp::camera: a free camera is DETACHED), CameraBuilder::shot adds them.

  • .new(tags: &'static [&'static str], f: impl Fn(&mut CameraArgs) + Send + Sync + 'static) -> ShotYours: |a| a.out.pos = .., with these tags (comp::camera). source

#

Text on its way to the screen: it goes when this is dropped, at the end of the statement.

  • .to(who: impl Into<Who>)Who sees it, of the players on the server (everyone in the dimension unless said); a client shows it only if this takes it in. source
  • .id(id: &'a str)New text with the same place and id replaces this one instead of adding another: a timer counting in one chat line, several free texts side by side. Empty key and no args takes it away. source
  • .at(x: f32, y: f32)This point of the text at the same point of the window, in fractions of either: (0, 0) the top left corner of both, (0.5, 0.5) centered, (1, 1) the bottom right corner of both. It stands by itself then, whatever its place. source
  • .scale(scale: f32)How big, 1 being menu text. A title is 4, a subtitle 2. source
  • .times(fade_in: f32, stay: f32, fade_out: f32)Seconds of fading in, staying and fading out. source
  • .color(rgb: u32)0xRRGGBB, for what doesn't color itself. source

#

A place for text a mod adds (Registry::text_place): an element of the HUD the player can move and hide, and how text there looks unless show says otherwise.

  • .hud(anchor: &str, order: i32)Where the HUD puts it by default: an anchor (hud_anchor::TOP_RIGHT) and its order there. source
  • .at(x: f32, y: f32, dx: f32, dy: f32)A spot of its own by default instead: this point of it at the same point of the window, moved by dx, dy GUI pixels. source
  • .scale(scale: f32)How big, 1 being menu text. source
  • .times(fade_in: f32, stay: f32, fade_out: f32)Seconds of fading in, staying and fading out, by default. source
  • .stacks()Several texts at once, one under another; by default a new one replaces what is there. source
  • .class(class: &str)Theme class of its text (label by default). source
  • .sample(key: &str)The translation the HUD editor shows while the place is empty. source
