What a World can do, shapes, directions, conditions.

#

What a block state is besides its components (those: components_of): its block, the mod it is from, its flags, light, look and feel. None for a state that doesn't exist.

  • .solid() -> bool source
  • .opaque() -> bool source

#

A condition (abi::condition): one of the engine's below, a registered one (Cond::from(&conditions::NIGHT), Cond::with(&MY_COND, "lava")) or written out (Cond::new("night & light(..7)")), put together with &, | and !. Loot tables, spawning, poses, music, camera modes and text ({if:..}) all take them, and w.holds asks one.

  • .new(text: &str) -> Cond source
  • .with(c: &crate::Condition, arg: &str) -> CondA registered condition with its argument, name(arg). source
  • .text() -> &str source
  • .chance(p: f32) -> CondHolds that share of the times it is asked. source
  • .light(min: u32, max: u32) -> CondThe light there, inclusive (0..15): the brighter of sky light times daylight and block light. source
  • .block(what: &str) -> CondThe block asked about is one what takes (a block matcher): one broken, one under a spawn. source
  • .side(d: crate::Dir, what: &str) -> CondThe cell on side d of the one asked about has a block what takes, or (empty) is solid. Not known while unloaded, so a rule waits. In a block's rule the side is of its own frame. source
  • .beside(d: crate::Dir, what: &str) -> CondA block horizontally next to the cell on side d is one what takes. source
  • .open(d: crate::Dir) -> CondSide d can be fallen into: air, a liquid, what placing replaces. source
  • .covered() -> CondSomething opaque is on top. source
  • .state(props: &str) -> CondThat block has these properties, written as in w.prop: state("age=7") for a ripe crop. source
  • .tool(tag: &str) -> CondWhat it was broken or killed with carries the tag (tools/shears). source
  • .tool_level(level: u32) -> Cond source
  • .killed_by_player() -> Cond source
  • .on_fire() -> Cond source
  • .harvested() -> CondThe block was harvested: broken by the world, or mined with a tool its mined_by level accepts. drops(..) tables have it; write it on pools of your own tables that should. source
  • .in_liquid() -> CondThe body asked about is in a liquid it swims in, flies, sprints (poses). source
  • .flying() -> Cond source
  • .sprinting() -> Cond source
  • .attribute(a: &crate::Attribute, min: f64, max: f64) -> CondAn attribute of the body asked about is within min..=max: attribute(&attribute::CAN_FLY, 1.0, f64::MAX) where it may fly. source

#

A fill in the making (World::fill); it happens as this goes.

  • .keep(what: &str)Blocks what takes stay (a block matcher: "#unbreakable #liquids"), on top of what an earlier keep said. One naming a block nobody has is a mistake the fill logs instead of happening. source
  • .only(what: &str)Only blocks what (or an earlier only) takes change (a block matcher): ore veins in stone only. source

#

How a block's model is turned (State::orientation, one of abi::Turn's 24). A model is written once facing north, its top up; boxes, model files, hitboxes, a cube's faces, liquid walls and support all turn with it. .facing(..), .axis() and redstone's attach and front turn their states by themselves.

  • .new(attach: Dir, front: Dir) -> OrientationIts bottom against attach, its front to front; a front along attach takes another way. source
  • .front(facing: Dir) -> OrientationIts front to facing, its top up unless the front is (then to the north, under it to the south). source
  • .up(facing: Dir) -> OrientationIts top to facing (a piston's head). source
  • .leaning(attach: Dir) -> OrientationUpright, its own west against attach (a torch on a wall). source
  • .axis(axis: &str) -> OrientationIts top along axis x, y or z (a log). source
  • .dir(d: Dir) -> DirWhere its own d goes. source
  • .own(d: Dir) -> DirIts own direction that goes to d. source
  • .turn() -> abi::Turn source
