Particles, bursts and what the GPU does with them.

#

Particles sent when this is dropped: w.spawn_particles(&SPARK, pos).count(10).speed(1.5).

  • .to(who: impl Into<crate::Who>)For whom, of the players on the server (those near it unless said). source
  • .area(shape: &crate::Shape)The particles start anywhere inside shape (a ring, a shell, a magic circle) instead of a box around the position; outward sends them away from the position. source
  • .count(n: u32) source
  • .spread(s: f32)Each particle starts up to this far from the position on every axis. source
  • .spread_box(s: impl Into<Vec3>)spread of its own on each axis: a flat sheet, a column. source
  • .velocity(v: impl Into<Vec3>)Starting velocity, blocks per second. source
  • .speed(s: f32)Random extra velocity up to this, in any direction. source
  • .color(rgb: u32)0xRRGGBB the kind's color is multiplied by: one white kind in any color. source
  • .outward(mut self)Each flies away from the middle of the burst, more or less, like the pieces of a broken block. source
  • .block(state: u32)Block state the textureless kinds (block dust) take their texture from. source

#

  • .post_effect(effect: &crate::Shader, strength: f32) -> boolTurns a screen effect (shaders/post/<name>.wgsl) on at strength (0 turns it off). source

#

What a condition is asked about.

  • .world() -> Option<World>The server's world, when the server asks (loot, spawning). source
  • .client() -> Option<ClientView>The client, when it asks (music, text): its own player. source
  • .pos() -> Vec3The spot, the block, the player. source
  • .entity() -> u64Who it is about (the killer or breaker for loot), 0 for nobody. source
  • .arg() -> &strWhat is between its parentheses where it is used, empty for none. source

#

Background music being registered (Registry::music): after a quiet while, a track of the first music whose conditions hold.

  • .tracks(names: &[&str])Files streamed (sounds/<name>.ogg|.wav), relative to this mod. source
  • .dimension(dimension: &crate::Dimension) source
  • .when(c: impl Into<crate::Cond>)Plays only while this holds (&conditions::NIGHT, a mod's own, any Cond); call again for more, all of which have to hold. source

#

A particle kind being registered (Registry::particle): half a second to a second, a tenth to a fifth of a block, white, without gravity, unless told otherwise.

  • .on_land(when: When, then: Then)What landing on a block does where when holds; rules are tried in order, and without one that holds it lies there. Any landing or hitting rule makes it stop on blocks. source
  • .on_wall(when: When, then: Then)Running into a block's side; without a rule it slides along. source
  • .on_ceiling(when: When, then: Then)Running into a block's underside; without a rule it stops. source
  • .on_enter_liquid(when: When, then: Then)Going into a liquid (when asks about that liquid). source
  • .on_leave_liquid(when: When, then: Then)Coming out of one: a bubble pops. source
  • .on_expire(when: When, then: Then)The end of its life: by default the end of it, Then::turn_into goes on as another kind (a spark dying into smoke). source
  • .textures(names: &[&str])Frames over its life; relative names are under particle/. None: block dust (pieces of the burst's block). source
  • .life(min: f32, max: f32)Seconds, picked between the two. source
  • .size(min: f32, max: f32)Edge length in blocks, picked between the two. source
  • .gravity(g: f32)Blocks per second squared, pulling down (negative rises). source
  • .drag(d: f32)Fraction of speed kept per tick (vanilla 0.98). source
  • .color(start: u32, end: u32)0xRRGGBBAA at birth and at the end of its life. source
  • .colliding()Stops on blocks: lies where it lands, slides along walls. source
  • .fullbright() source
  • .translucent() source
  • .shrinking() source
  • .shader(shader: &crate::Shader)Colors it with shaders/particle/<name>.wgsl (fn shade(p: ParticleFrag) -> vec4<f32>). source

#

A sound about to play (Output::play_sound).

  • .to(who: impl Into<crate::Who>)Who hears it, of the players on the server (those in its range unless said). source
  • .pitch(pitch: f32)Playback speed (1 = as recorded, 2 an octave up) instead of one picked from the sound's range: a note block's 2f32.powf((key - 12) as f32 / 12.0). source

#

A sound event being registered (Registry::sound): at volume 1 and as recorded, heard 16 blocks away, a block sound, unless told otherwise.

  • .files(names: &[&str])Variants picked at random: sounds/<name>.ogg or .wav, relative to this mod. source
  • .category(category: &SoundCategory)Category for its volume setting: the engine's (core:creatures ...) or one registered with Registry::sound_category (any mod's). source
  • .volume(v: f32) source
  • .pitch(min: f32, max: f32)Playback speed picked between the two. source
  • .range(blocks: f32)Blocks away it is still heard. source
  • .falloff(full_within: f32, curve: Falloff)Full volume within full_within blocks, then fading to nothing at range along curve (by default within 1 block, evenly). source

#

What a particle's rule does.

  • .die() -> Then source
  • .stop() -> ThenStays where it is for the rest of its life. source
  • .slide() -> ThenKeeps going along what it hit. source
  • .bounce(share: f32) -> ThenComes back off what it hit with share of its speed. source
  • .turn_into(kind: &Particle) -> ThenBecomes a particle of kind where it is, its speed kept and its life starting anew; kind must be drawn the same way (translucent or not). source
  • .turn_into_still(kind: &Particle) -> Thenturn_into, standing still: a ripple where a drop fell. source

#

Where a particle's rule holds: the block it hit, or the one it is in.

  • .any() -> When source
  • .liquid() -> When source
  • .tag(tag: &str) -> WhenA block with tag (water, lava, a mod's own). At most 5 different tags over all particle kinds of the game: the GPU keeps them with each block. source
